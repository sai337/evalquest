# Launch kit

## 1. Repo settings (2 minutes, on GitHub → About ⚙️)
- **Description:** `A free game that takes you from beginner to SME in LLM & AI-agent evals. Judge agent traces, build LLM judges, prove they agree with humans.`
- **Website:** the live game URL
- **Topics:** `llm-evaluation` `evals` `ai-agents` `llm-as-a-judge` `agent-evaluation` `llmops` `genai` `learning-game` `education` `ai-engineering`
- **Social preview** (Settings → General): upload `docs/img/judge.png`
- Turn on **Discussions**; pin a "Which industry pack should be next?" thread
- Label 3–5 `new-pack` issues as `good first issue` (insurance, coding agent, SRE/NOC, travel, HR)

## 2. Posts (edit into your own voice)

**LinkedIn**
> Most AI teams can build an agent. Far fewer can tell you whether it works.
> I built EvalQuest, a free, open-source game that teaches evals by making you do them: read agent traces from banking, e-commerce and contact-center bots, spot the failure, and build an LLM judge, then see its confusion matrix against human labels.
> My favourite lesson: a judge with 92% agreement can still miss 70% of real failures.
> Play (no sign-up): <link> · Repo: <link> · Packs for your industry welcome.

**Show HN:** `Show HN: EvalQuest – a game for learning to evaluate AI agents`
First comment: why you built it, the Judge Builder mechanic, that grading is deterministic and offline, and the ask for domain packs.

**Reddit** (r/LLMDevs, r/LocalLLaMA, r/MachineLearning on the weekly self-promo thread): lead with the 92%-agreement puzzle as a question, then link.

## 3. Compounding
- Submit a PR adding EvalQuest to curated "awesome" lists about LLM evaluation and AI agents (search GitHub for them; follow each list's rules).
- Ship one new pack every week and post the most surprising puzzle from it. Every pack is a new reason to share.
- Thank and credit every pack contributor in the release notes.
